# Módulo 03: Criação do Agente de IA e Base de Conhecimento

## 🇧🇷 Português (PT-BR)
Este módulo Terraform automatiza o provisionamento do **OCI Generative AI Agents**, incluindo a criação da Base de Conhecimento (Knowledge Base), pipeline de ingestão de dados e o endpoint ativo do Agente de IA.

### Recursos Provisionados via Terraform:
- **Knowledge Base:** Configuração de vetor de busca indexado aos documentos do Object Storage.
- **OCI GenAI Agent:** Criação e parametrização do agente de suporte automatizado.
- **Agent Endpoint:** Endpoint de publicação para chamadas de API e testes de integração.

---

## 🇺🇸 English (EN)
This Terraform module automates the deployment of the **OCI Generative AI Agents** service, including Knowledge Base vector indexing, data ingestion pipeline, and the active AI Agent endpoint.

### Provisioned Resources via Terraform:
- **Knowledge Base:** Vector search configuration referencing PDFs stored in Object Storage.
- **OCI GenAI Agent:** Creation and configuration of the automated support agent.
- **Agent Endpoint:** Published endpoint for API calls and integration testing.
