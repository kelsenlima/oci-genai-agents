# Módulo 04: Testes de Validação e Execução do Agente de IA

## 🇧🇷 Português (PT-BR)
Este módulo contém os ativos de validação, suite de prompts e scripts de teste de integração para interagir com o endpoint do **OCI Generative AI Agent** criado nos módulos anteriores.

### Conteúdo do Módulo:
- **`test_prompts.json`**: Coleção de prompts de teste focados em casos de uso de Suporte ao Cliente, inferência vetorial RAG e consultas dinâmicas.
- **`test_agent_api.py`**: Script em Python usando o OCI Python SDK para simular sessões de chat e interações com o agente via API[cite: 3].

## 🇺🇸 English (EN)
This module contains validation assets, prompt suites, and integration test scripts for interacting with the **OCI Generative AI Agent** endpoint built in the previous modules[cite: 3].

### Module Contents:
- **`test_prompts.json`**: Test prompt dataset focusing on Customer Support scenarios, RAG vector retrieval, and dynamic query responses[cite: 3].
- **`test_agent_api.py`**: Python script utilizing the OCI Python SDK to simulate chat sessions and agent endpoint interactions via API[cite: 3].
