# OCI Generative AI Agents - Framework de Implementação e Automação

[PT-BR] Este repositório é uma suíte técnica completa para provisionamento, configuração e teste do **OCI Generative AI Agents** utilizando Infraestrutura como Código (Terraform) e scripts de integração.

[EN] This repository serves as a complete technical suite for deploying, configuring, and testing **OCI Generative AI Agents** using Infrastructure-as-Code (Terraform) and integration scripts.

---

## 📁 Estrutura de Módulos / Module Structure

- **`01-iam-and-storage/`**: Automação de Políticas IAM, Grupos Dinâmicos e Buckets de Object Storage para os Agentes de IA.
  *(Automation for IAM Policies, Dynamic Groups, and Object Storage Buckets required by OCI GenAI Agents.)*
- **`02-knowledge-base-and-agent/`**: *(Em breve / Upcoming)* Módulos Terraform e scripts para criação de Vector Databases, Knowledge Bases e endpoints de Agentes de IA.
- **`03-mcp-integrations/`**: *(Em breve / Upcoming)* Deploy de servidores MCP (Model Context Protocol) em OCI Container Instances e API Gateway.
